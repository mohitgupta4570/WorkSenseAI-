Important dataset note:
The uploaded dataset is a Nine-Box employee talent dataset. It does not contain direct sentiment or workplace-issue labels.
Therefore, this phase uses transparent weak supervision. Sentiment is derived primarily from human-provided performance_class labels, while issue categories are derived from domain keyword rules. The generated labels are then used to train reusable ML classifiers.
